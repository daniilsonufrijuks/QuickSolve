# Cursor AI Master Prompt — QuickSolve

## Laravel + Vue.js + MySQL

Act as a senior full-stack engineer, Laravel architect, Vue.js developer, UI/UX designer, and SaaS product strategist.

Build **QuickSolve**, a modern, monetizable web platform that combines:

1. Free online utilities to attract organic search traffic.
2. Premium B2B tools to generate recurring revenue.
3. Digital downloads to generate one-time sales.

The application must be a functional, production-minded MVP, not just a landing page or UI prototype.

---

# 1. Technology Stack

Use this stack:

### Backend

* PHP 8.3 or a version compatible with the installed Laravel version.
* Laravel 12 or the latest compatible stable Laravel version.
* Laravel REST API architecture.
* Laravel Sanctum for authentication.
* MySQL 8+.
* Laravel Eloquent ORM.
* Laravel Form Requests for validation.
* Laravel Policies and Gates for authorization.
* Laravel Queues for background tasks where appropriate.
* Laravel Scheduler for recurring maintenance tasks.
* Laravel filesystem for private downloads.
* PHPUnit or Pest for automated tests.

### Frontend

* Vue 3.
* TypeScript.
* Composition API with `<script setup>`.
* Vite.
* Vue Router.
* Pinia for shared state when needed.
* Tailwind CSS.
* shadcn-vue or a compatible accessible component library.
* Lucide icons for Vue.

### Integrations

* Stripe for subscriptions and one-time purchases.
* Laravel Cashier for Stripe subscription management, if compatible with the selected Laravel version.
* Supabase is NOT required; MySQL is the primary database.
* An optional AI provider for product-description generation.
* A transactional email provider for receipts and notifications.

Use compatible, stable package versions. Inspect the existing repository before installing packages or replacing files.

Use a Laravel API backend and a Vue SPA frontend. Configure Laravel Sanctum correctly for first-party SPA authentication, including CSRF protection, session cookies, CORS, and trusted stateful domains.

If the repository already uses Laravel with Vue and Inertia, preserve that architecture unless there is a strong reason to migrate. Do not introduce unnecessary architectural complexity.

Requirements:

* RESTful API endpoints under `/api/v1`.
* Consistent JSON response structures.
* Server-side validation.
* Centralized exception handling.
* Eloquent models and relationships.
* Database migrations and seeders.
* API authentication and authorization.
* Pagination for listings.
* Rate limiting for expensive operations.
* Environment-based configuration.
* Separate development and production settings.

Never expose private keys, Stripe secrets, AI provider keys, or other server credentials in the Vue frontend.
